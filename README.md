# the knight 
## it is a platform game that you must collect the 13 coin 
## AI used
only to explain something
## Engine 
Godot
## how to play 
 1- open this link ( https://baraamo1.itch.io/the-knight )
 2- use A or left arrow to go left
 3- use D or right arrow to go right
 4- use space or up arrow to jump
